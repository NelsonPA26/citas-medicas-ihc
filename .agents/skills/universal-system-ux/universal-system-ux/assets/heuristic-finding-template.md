### Escala de severidad sugerida

- `0`: no es problema.
- `1`: cosmético; no impide la tarea.
- `2`: menor; causa demora o duda recuperable.
- `3`: mayor; provoca errores, abandono parcial o dificultad seria.
- `4`: catastrófico; bloquea una tarea crítica, causa pérdida de datos, riesgo o exclusión grave.

### Escala de frecuencia sugerida

- `0`: no ocurre o no aplica.
- `1`: rara vez o en una condición extrema.
- `2`: ocasionalmente o para un segmento limitado.
- `3`: frecuentemente o en una ruta habitual.
- `4`: siempre, casi siempre o para la mayoría de usuarios afectados.
